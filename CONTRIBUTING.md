# Contributing / 参与贡献

Thank you for your interest in improving this project.

## 中文

如果你想帮助这个项目，可以通过以下方式参与：

- 提交 Issue 反馈问题
- 提交 Pull Request 修复问题或改进文档
- 提出新的功能建议

在提交问题前，建议先查看：

- [README.md](README.md)
- [README-en.md](README-en.md)
- [TROUBLESHOOTING.md](TROUBLESHOOTING.md)

## English

If you would like to help improve this project, you can:

- Open an issue to report a problem
- Submit a pull request to fix bugs or improve documentation
- Share a feature suggestion

Before opening an issue, please review:

- [README.md](README.md)
- [README-en.md](README-en.md)
- [TROUBLESHOOTING.md](TROUBLESHOOTING.md)

## Notes

- Keep changes focused and easy to review.
- For server-side issues, please include logs when possible.
- For installation issues, include your Linux distribution and version.
