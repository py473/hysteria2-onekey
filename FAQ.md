# FAQ / 常见问答

## 中文

### 1. 这个脚本支持哪些系统？

支持常见的 Linux / Unix 服务器系统，例如 Debian、Ubuntu、Rocky Linux、CentOS Stream 和 Fedora。

### 2. 如何一键安装？

推荐使用：

```bash
wget -O /tmp/hysteria2-onekey-install.sh https://github.com/py473/hysteria2-onekey/raw/main/install.sh && bash /tmp/hysteria2-onekey-install.sh
```

### 3. Salamander 和 Gecko 混淆有什么区别？

- **Salamander**：将每个数据包打乱为看似随机字节，兼容性较好。
- **Gecko（实验性）**：在 Salamander 基础上，还对 QUIC 握手包进行分片和随机填充，能更有效地绕过对 QUIC 协议特征的检测。

启用任意一种混淆后，服务器不再兼容标准 QUIC/HTTP/3 连接。

### 4. 混淆密码需要和服务端一致吗？

是的。客户端和服务端必须使用相同的混淆方式和密码，否则连接会失败。使用本脚本生成的客户端配置文件 `/root/hy2-client.yaml` 会自动包含混淆配置。

### 5. 为什么 v2rayN 连不上？

通常是以下原因之一：

- 服务器没有监听 UDP 443
- 云厂商安全组没有放行 UDP 443
- 证书或 SNI 配置不一致
- 启用混淆但 v2rayN 版本不支持或未正确配置混淆参数

请先查看 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。

如果你想查看支持哪些客户端和官方下载地址，请看 [CLIENTS.md](CLIENTS.md)。

### 6. 伪装地址要怎么填？

可以直接输入域名，例如 `www.bing.com`。

脚本会自动补全 `https://`。

### 7. 如何升级到最新版本？

直接重新运行一键安装脚本即可。Hysteria 2 官方安装脚本会自动下载并覆盖安装最新版本。运行 `hysteria version` 查看当前版本。

## English

### 1. Which systems are supported?

Common Linux / Unix server systems are supported, including Debian, Ubuntu, Rocky Linux, CentOS Stream, and Fedora.

### 2. How do I install it in one line?

Recommended command:

```bash
wget -O /tmp/hysteria2-onekey-install.sh https://github.com/py473/hysteria2-onekey/raw/main/install.sh && bash /tmp/hysteria2-onekey-install.sh
```

### 3. What's the difference between Salamander and Gecko obfuscation?

- **Salamander**: scrambles every packet into random-looking bytes. Better compatibility.
- **Gecko (experimental)**: builds on Salamander and additionally fragments QUIC handshake packets into randomly-sized, randomly-padded datagrams. More effective at evading QUIC protocol fingerprinting.

Enabling either obfuscation mode makes the server incompatible with standard QUIC/HTTP/3 connections.

### 4. Does the obfuscation password need to match on the server and client?

Yes. Both the server and client must use the same obfuscation type and password, otherwise connections will fail. The client configuration file `/root/hy2-client.yaml` generated by this script will automatically include obfuscation settings.

### 5. Why does v2rayN fail to connect?

Common reasons include:

- The server is not listening on UDP 443
- The cloud firewall does not allow UDP 443
- Certificate or SNI mismatch
- Obfuscation is enabled but v2rayN version does not support it or is not properly configured

Please check [TROUBLESHOOTING.md](TROUBLESHOOTING.md) first.

If you want to see supported clients and official download links, check [CLIENTS.md](CLIENTS.md).

### 6. How should I enter the masquerade URL?

You can enter a plain domain such as `www.bing.com`.

The script will automatically prepend `https://`.

### 7. How do I upgrade to the latest version?

Simply re-run the one-key installer. The official Hysteria 2 installation script will automatically download and overwrite with the latest version. Run `hysteria version` to check the current version.
